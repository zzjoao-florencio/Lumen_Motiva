# Como contribuir

O LÚMEN é um protótipo acadêmico. Para sugerir melhorias:

1. Abra uma issue descrevendo o problema ou a melhoria pretendida, **sem publicar dados privados**.
2. Faça uma branch específica para a alteração e mantenha o escopo pequeno.
3. Preserve a navegação, os temas roxo e branco e a indicação de que o conteúdo é demonstrativo.
4. Não introduza credenciais, endereços reais de câmeras, dados operacionais privados ou dependências sem revisão.
5. Execute `python scripts/security_check.py` antes do commit.
6. Teste visualmente as abas no navegador, incluindo a tela mobile, e descreva o que foi validado no pull request.

Alterações em dados ou regras de priorização devem explicar a origem dos valores e deixar claro quando forem simulados. A proposta futura de Python/OpenCV e sensores não deve ser descrita como funcionalidade já implementada.
